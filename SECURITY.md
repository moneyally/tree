# Security policy

Tree is in early development and has not been audited yet.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private vulnerability reporting
("Report a vulnerability" in the Security tab of this repository).

Include what you found, how to reproduce it, and the impact you expect. We will
acknowledge the report, keep you updated, and credit you when the fix ships unless
you prefer otherwise.

## Scope

- `crates/tree-core`: cryptography, group handling, feature registry
- later: server, apps, bot gateway
