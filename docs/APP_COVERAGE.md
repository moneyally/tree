# 앱 화면 연결 현황 (새 디자인 기준)

엔진(Rust 코어 + FFI)에 있는 기능이 새 화면(`apps/ui`)에서 실제로 쓸 수 있는지
정리한 표. 2026-10-05 점검.

- FFI 함수 252개 중 215개는 앱 모델(`apps/shared`)이 감싸고 있다.
- 그중 상당수는 예전 PC 화면에서만 쓰였고, 새 화면으로 아직 옮기지 않았다.
- 표시: ✅ 새 화면에서 동작 · 🟡 엔진·모델에 있음, 화면 없음 · 🔴 모델에도 없음(FFI만) · ⚪ 엔진에 없음

1. 대화 기본: 전달, 여러 개 선택, 알림 끄기 기간, 조용히 보내기, 서식·멘션, 대화방 안 검색

3. 단톡 관리: 관리자 지정·내보내기, 역할, 발언 제한, 가입 승인, 환영 메시지, 관리 기록, 링크 취소

## 디자인 원칙 (기계가 만든 티 안 나게)

- 설명 문장은 꼭 필요한 곳에만. 버튼·메뉴는 두세 글자 동사("보내기", "전달", "차단").
- 같은 종류는 같은 모양: 목록은 `SettingsRow`, 묶음은 `CardGroup`, 확인은 같은 대화상자.
- 아이콘은 한 세트(Material Rounded)만, 색 타일은 설정 화면에만.
- 이모지·느낌표·"~해 보세요!" 같은 들뜬 말투 금지. 존댓말 "~해요"로 짧게.
- 같은 정보를 두 번 보여주지 않기(예: 상단에도 본문에도 "암호화" 문구 X).
- 빈 화면은 아이콘 + 한 줄 + 할 일 버튼 하나.
